# Full roster artwork provenance

Six original transparent atlases were generated on 22 September 2026 using the built-in image generation tool. No extracted EA sprites were used as source artwork. The earlier construction-yard sheet is reused; its original prompt remains in README.md.

Vehicle sheets use overhead hulls and separate turrets. Building sheets use 5 × 4 cells. Infantry sheets use eight authored views for each of eight roles. The compiler imports the largest connected silhouette in each cell to remove neighbouring-cell fragments, scales it, generates deterministic animation states and quantizes it to the map's own palette. Vehicle directions are rotated before vertical foreshortening; infantry use the actual directional drawings.

The source PNG files are preserved as generated. Specialist chassis reuse is recorded in ROSTER.md. Animation and image conversion are reproducible code, with no additional image-generation call needed to rebuild.
